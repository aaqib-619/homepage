02 · Event sliderR1R2APP
  • Each slide has a colour-coded pillar tag, title, panel and chair, date, time and venue, and a ticket button that adds that day's series pass to the cart.
  • Six curated slides cover all five pillars. They're the events marked Featured in The Events Calendar, so the hero comes from the same data as the programme.

      06 · ProgrammeR2WPAPP
      • The panel copies The Events Calendar v2 list view as Events Calendar Pro renders it on a series page (e.g. /series/day-1-pass/), down to the class names: tribe-events-c-events-bar, …calendar-list__event-row, the date tag, …small-cta, the nav and Subscribe to calendar.
      • It's styled only through what the plugin exposes: Customizer accent colour and fonts, plus short CSS. On desktop the image sits right; on phones it stacks above the details.
      • The day tabs are a thin custom wrapper, one per Day series, and stick under the header on phones. Pillar chips are TEC event categories. Tapping an event opens a sheet that mirrors the single-event page and the Event Tickets Plus form.

          08 · TicketsWPAPP
          • Three ticket stubs with square-notch perforations. On phones they swipe as a rail.
          • In WordPress each is an Event Tickets Plus ticket: the Day Pass is the series pass on that day's Event Series (Day 1, 2 or 3), the Festival Pass is a series pass covering all three, and the Student Pass is a free ticket.
          • ET+ tickets are WooCommerce products, so the buttons use Woo's add_to_cart_button, data-product_id and the Store API. Prices are placeholders, set in Oldforge as on the early-bird posts.
